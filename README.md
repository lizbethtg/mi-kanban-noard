#  Mi Kanban Board

> Un tablero de gestión de tareas interactivo construido con HTML5, CSS3 y JavaScript Vanilla. Sin frameworks, sin librerías, solo código puro y lógica sólida.

## ✨ Características Destacadas

-   **Drag & Drop Nativo:** API HTML5 pura para mover tareas entre columnas.
-   **Edición Inline:** Doble clic para editar texto directamente en la tarjeta.
-   **Estadísticas Dinámicas:** Filtrado por mes con cálculos en tiempo real.
-   **Persistencia Local:** Tus datos sobreviven al recargar gracias a LocalStorage.
-   **Diseño Moderno:** UI limpia con paleta lila/rosa y animaciones suaves.

## 🛠️ Stack Tecnológico

| Tecnología | Rol |
| :--- | :--- |
| HTML5 Semántico | Estructura accesible |
| CSS3 (Variables, Flexbox, Grid) | Diseño responsivo y theming |
| JavaScript ES6+ | Lógica, DOM manipulation, LocalStorage |
